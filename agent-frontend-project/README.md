# Vue 3 + TypeScript + Vite

## 项目描述

这是一个使用 Vue 3、TypeScript 和 Vite 构建的前端项目脚手架。它旨在为构建高质量的 Web 应用程序提供一个现代化、高效且可扩展的开发环境。

## 开始使用

### 环境准备

- [Node.js](https://nodejs.org/) (版本 16 或更高)
- [pnpm](https://pnpm.io/) (可选，但推荐使用)

### 安装

1. 克隆仓库:
    ```bash
    git clone <repository-url>
    ```
2. 进入项目目录:
    ```bash
    cd agent-frontend-project
    ```
3. 安装依赖:
    ```bash
    npm install
    # 或
    pnpm install
    ```

## 可用脚本

在项目目录中，您可以运行:

- `npm run dev`: 在开发模式下运行应用。
- `npm run build`: 构建用于生产的应用。
- `npm run preview`: 在本地预览生产版本。
