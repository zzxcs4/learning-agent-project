# openai SDK：**必须落在 langchain-openai 的约束里（>=2.26.0,<3.0.0）**，否则整条 AI 链路会崩。
#
# 为什么单独钉这一条（2026-10-20 实际踩到）：langchain-openai 只声明了上界 `openai<3.0.0`，
# 而本项目原先**没有**把 openai 写进依赖，于是 `pip install --upgrade "openai>=1.0"`
# 会直接把它升到 3.x。openai 3.x 把 HTTP 客户端从 `httpx` 换成了 `httpx2`（两个库的
# `SyncByteStream` 是**不同的类**），而 langchain-core 会传一个普通 `httpx.Client` 进去，
# 请求到达 httpx 的 transport 时被类型断言拦下：
#     httpx2/_client.py:1076 -> httpx/_transports/default.py:234
#     assert isinstance(request.stream, SyncByteStream)  -> AssertionError
# 症状：agent loop / 出题 / 单轮聊天（凡走 langchain 的）全部报错；而 `pip check` 只有一行
# 警告、裸 `OpenAI` SDK 反而能正常连服务端，很容易被误判成"只是版本新了一点"。
